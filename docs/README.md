# docs 文档索引

本目录存放项目所有文档类文件。

## 命名规范

- 文件名：英文小写 + 连字符（如 `plan.md`、`coding-style.md`）。
- 所有文档类文件统一放在 `docs/`，不在其他位置新建文档。

## 文档列表

| 文件 | 说明 |
| --- | --- |
| [plan.md](plan.md) | 项目学习计划（工程规范版） |
| [tetris-warmup.md](tetris-warmup.md) | 阶段 0 俄罗斯方块热身项目开发文档 |

## 维护约定

- 新增文档后在此索引追加一行。
- 文档用中文撰写，代码示例与标识符用英文。
